# 看板改为跨来源发现流

## 上下文

[0008](0008-source-grouped-board.md) 按来源纵向分块。实际使用中,目标是发现值得尝试的项目,按来源分区让用户来回扫找,且无法回答「该怎样筛选」。AI 自动判断暂留后续,当前 UI 应先让人快速比较、搜索、保存与回看。

## 决定

- 热点放在同一条信息流,不按来源分组,也不提供来源筛选。每张卡仍标明来源和该来源内的榜单名次。
- 提供跨标题、简介、来源、语言和笔记的多词搜索;支持按首次发现时间或最近上榜日期与来源榜单名次排序。
- 不把不同来源的星标、点赞、下载量合成为全局分数。来源名次只在各自的榜单里解释。
- 提供本地「已收藏」视图。缓存裁剪时保留收藏条目;收藏 ID 和热点数据都留在 localStorage,不上传。
- 详情抽屉继续提供历史趋势、笔记和原始来源链接。计时器压缩到单行工具条。
- 这版不引入 agent 评估、自动项目质量判断或跨来源评分。

## 后果

首页从来源导航转为统一浏览和搜索。榜单排名是弱信号,帮助在同一来源中定位,不代表跨来源质量可比。后续若加入自动评估,应清楚区分来源原始信号与 agent 判断。
