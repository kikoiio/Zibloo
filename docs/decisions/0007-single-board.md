# 主界面改为一块看板

## 上下文

[0005](0005-board-home.md) 把主页做成五列判断(收件箱、观察、试用、灵感、忽略),并带观察名单和热点设置。用过之后不需要这套划分:热点和计时共用一块看板即可。日报仍要,用来和昨天对比。

## 决定

- 主页是一块看板。热点、训练、专注、快捷计时都是同一列表里的卡片。
- 侧栏只留看板和日报。删除观察名单和热点设置。
- 收取始终拉全部十个社区。不再开关来源,也不再按列藏起卡片。
- 点开热点仍可写笔记、打开来源。不再给卡片下五列判断,也不再拖列。
- 日报仍按新出现、还在加速、仍在榜上、掉出今日分组。日报不开始计时。

## 后果

计时仍在看板上倒计时,多张可以同时走。章鱼留在侧栏。[0006](0006-drop-reminders.md) 的「只留计时与热点」仍然有效。旧的 `zibloo.board.verdicts.v1` 与 `zibloo.board.settings.v1` 不再读取。
