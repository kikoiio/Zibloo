# 以 B2 五姿态帧做 2D 渲染

## 上下文

[0002](0002-character-and-brand-b2-c3.md) 冻结了角色原图。同日曾考虑 Blender 离线 3D 帧序列,用户要求删除 3D,回到 B2 / C3 原图。P0 原型 `p0-v2` 用原图与姿态帧验证了观感后于 2026-10-24 退役(提交 `5ad3bb6`,分支 `codex/prototype-b2-c3`;截图在 git 历史 `prototype/`)。

## 决定

- 使用以 B2 原图为基准的五张对齐姿态帧:四帧划水循环 + 一帧抬爪招呼。资产在 `static/zibloo/`。
- 整图只做轻悬浮与位移。专注与暂停静止。系统减少动态效果时冻结。
- 不使用模型、骨骼、Lottie 或 3D 渲染。不重开已否决的 3D 管线。
- 独立腕足动作、眨眼、分层精灵图不是首版前置;新增局部动作须先评审素材。

## 后果

`mapZibloo` 产出姿态语义,`ZiblooPresenter` 只消费该结构。缺帧时降级 idle,不崩溃。P0 里「点击水域游过去 / 方向键移动」未带入正式应用。
