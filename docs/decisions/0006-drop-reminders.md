# 看板只留计时与热点

## 上下文

[0005](0005-board-home.md) 把主页改成五列看板时,原有计时和提醒都还在列里。产品收成「timer + trending」:训练、专注、快捷计时留下,记事/提醒整条产品拿掉。

## 决定

- 看板卡片只来自热点缓存、训练模板与预设、专注时长、快捷分钟,以及钉上的计时计划。
- 删除提醒规则、提醒页、提醒状态与 Dexie 提醒表。备份信封仍是 v1,旧文件里的 `reminders` 字段解析时丢掉。
- 原生 `syncAlarms` / 提醒域仍留在插件里,启动时同步空集合,清掉旧安装残留的提醒闹钟。开机不再重建提醒域。
- 计时仍走 `syncTimerAlarms`。杀进程后段边界还能响;重启后计时域不重建,打开应用再按进行中的会话重排。

## 后果

产品验收从意图里的 V1–V6 收成 V1–V5,去掉「任一列提醒仍响」。可靠性不再要求重启后提醒还在。模拟器 Phase A 改成 1 分钟快捷计时杀进程后完成通知;Phase B 只确认重启后看板能打开。

2026-11-04:本文的原生提醒/计时闹钟实现与模拟器验收后果已由 [0009](0009-web-only.md) 取代;网页端不再保留这些代码或工作流。
