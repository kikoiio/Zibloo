# 角色 B2、字标 C3、场景小窝

## 上下文

产品是「一只陪你计时的章鱼」,角色造型与品牌组合必须先于实现冻结。用户于 2026-10-21 选择场景小窝方向并禁止紫色;2026-10-22 在概念板中同时选定 B2 与 C3。

## 决定

- **B2** 为主角色:修长柔软的腕足、S 形流线、圆钝末端、青绿 / 浅薄荷双配色、简洁眼睛、克制表情。腕足可伸展、回卷、触碰与拿放物件,不固定手持秒表。减少玩偶感;避免生物写实的皮肤纹理、密集吸盘、尖细末端与真实动物眼睛。
- **C3** 为角色与小写 `zibloo` 字标的品牌组合。用户选择的是整张概念板;上下两种组合均保留为参考。
- 造型不要求八条腕足同时可见;允许视角遮挡、自然收拢和符号化简化。
- 不重画字母、眼睛、头部或腕足,仅可屏蔽近白纸色背景。
