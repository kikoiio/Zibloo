# 主界面改为五列看板

## 上下文

Zibloo 原本是计时章鱼:小窝、间歇训练、专注、提醒。个人热点看板已经在桌面的 Trending 里做成五列判断(收件箱、观察、试用、灵感、忽略)。产品要收成一个应用:热点和原有计时都在看板上,计时不离开看板。提醒后来从看板上拿掉,见 [0006](0006-drop-reminders.md)。

## 决定

- 主页是这一套五列。热点条目、训练、专注、快捷计时都是卡片。
- 拖列只记录判断。不开始计时。
- 训练和专注在卡片上倒计时,允许多张同时进行。没有单独的运行页作为主路径。
- 章鱼留在看板上,跟随最近开始的那张计时卡。每张卡自己显示剩余时间。
- 热点收取沿用 Trending 的十个社区。开发时经本地代理取数;安卓上用 CapacitorHttp,避免浏览器跨域。

## 后果

`/run` 仍留在代码里,新的开始动作回到看板。计时引擎继续按锚点推导,多张会话各自一份 `Session`,段边界闹钟合并后同步。
