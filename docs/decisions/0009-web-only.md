# 当前只维护网页端

## 上下文

产品当前只需要热点与计时看板。额外的原生运行端带来独立代码、构建和验收工作,而眼下不需要这些能力。网页计时也不应暗示页面关闭后仍会触发提示。

## 决定

- 当前唯一开发和维护目标是浏览器网页;其他平台的开发暂停。
- 移除 Capacitor、Android 原生工程、原生闹钟与前台服务接口、APK/模拟器工作流及设备验收脚本。
- 继续保留 SvelteKit 静态网页、网页计时与声音、网页 CI 和网页冒烟检查。
- 浏览器后台可能降低计时精度;页面关闭后计时提示不会继续触发。
- 删除 GitHub Actions 中已有的 APK、模拟器证据与模拟器日志 artifacts。

## 后果

依赖和 CI 只服务网页端。静态部署直接从浏览器请求热点来源,会受到来源站点 CORS 策略限制。将来恢复其他平台开发前,先重新评估平台范围并更新本决策与产品意图。
