# Zibloo 产品意图

Zibloo 是一块个人看板。打开网页就看到按来源分块的热点,以及计时卡片。章鱼留在顶栏,用功能不用先点它。

当前实现见 [`architecture.md`](architecture.md)。当前只开发和维护网页端;其他平台开发已暂停。

## 谁、场景、非目标

- **用户**:开发者自己。
- **形态**:浏览器中的网页应用。
- **打开之后**:
  1. 各社区 trending 收成卡片,按来源分块落在看板上
  2. 训练、专注、快捷计时在「计时」块的卡片上倒计时,可以多张同时走,不进入单独的运行页
- **这版不做**:五列判断、侧栏、日报、观察名单、热点设置、来源筛选芯片。
- **已不做**:提醒 / 记事。看板只留计时与热点。
- **平台范围**:当前只做网页端;其他平台的开发和发布暂停。
- **仍不做**:云账号。

## 看板

主界面是一块大看板。收取把 GitHub、Hacker News、Lobsters、Hugging Face、GitLab、crates.io、DEV、Flathub、Product Hunt、X 的今日榜拉成卡片,按来源分块纵向排列,整页一起滚。点开热点可写笔记、打开来源。收取仍是手点,始终拉全部来源。GitHub token、周榜语言分榜这版不做。

训练、专注、快捷计时放在「计时」块。倒计时、暂停、跳过本段、结束画在卡片上。跑完卡片留在看板上。同一时间可以有多张卡在走。章鱼跟随最近开始的那一张;每张卡自己显示倒计时。没有单独的训练、专注、历史、设置页。

## 可靠性

1. 进行中的倒计时由锚点时间推导,不把剩余秒数写进存储。暂停期间不走字。
2. 页面运行且可见时,计时段边界播放提示音。
3. 浏览器可能降低后台页面的计时精度;页面关闭后不会触发计时提示。

## 验收

| # | 标准 |
|---|---|
| V1 | 打开即一块看板,热点按来源分块,训练、专注、快捷在计时块 |
| V2 | 没有侧栏、日报、五列并排分栏 |
| V3 | 多张训练或专注可以同时在看板上倒计时 |
| V4 | 章鱼在看板上,功能不依赖点它 |
| V5 | 计时投影、热点合并、状态映射仍有单元测试 |
