# Zibloo 产品意图

Zibloo 是一款计时器应用。它不是「带吉祥物的计时器」,而是「一只陪你计时的章鱼」:Zibloo 是产品的灵魂、导航的载体、声音的签名和品牌的全部。

当前实现见 [`architecture.md`](architecture.md)。品牌与技术选型见 [`decisions/`](decisions/)。

## 谁、场景、非目标

- **用户**:大众用户,无特定限制;开发者本人是第一用户。
- **形态**:安卓 App(APK 直装分发)+ 网页版,同一套代码。暂不上架应用商店,暂不做 iOS。
- **核心场景**:
  1. 间歇训练:跟练时不用盯屏幕,靠叫声知道当前段
  2. 专注工作:Zibloo 安静陪伴
  3. 生活提醒:Zibloo 跳出来叫你
- **非目标(首版)**:云账号、iOS、应用商店上架、养成经济系统(喂食 / 货币 / 数值成长)。角色与标志不固定绑定秒表或时钟,为计时器之外的扩展留空间,但不扩大首版功能。

## 角色

Zibloo 悬浮在主页的海底小窝中。用户使用计时器,就是在让它「工作」。表现是当前活动状态的纯映射,无持久数值。同一状态在 UI 上表现一致。锁屏 / 后台时降级为通知,不做后台动画。

| 状态 | 触发 | 表现方向 |
|---|---|---|
| 待机 | 无计时活动 | 小窝里漂浮、可点按互动(叫声 + 小动画) |
| 训练陪伴 | 间歇训练运行中 | 运动段加油、休息段放松,呼应叫声语义 |
| 专注安静 | 番茄钟运行中 | 收起触手安静陪伴;进入休息时苏醒伸展 |
| 提醒召唤 | 提醒触发 | 跳出、醒目动作 + 叫声 + 震动 |
| 庆祝 | 任意计时完成 | 欢快动作 + 欢快三连叫声 |

造型与品牌方向见 [0002](decisions/0002-character-and-brand-b2-c3.md)、[0003](decisions/0003-2d-pose-frames.md)。禁止紫色。腕足构图允许视角遮挡与自然收拢,不要求八条同时可见。

**后期轻养成**:连续使用解锁纯视觉内容(姿态、装饰);断用后展示回落、已解锁内容保留。不做喂食、货币、等级。

## 听觉

默认提示音为 Zibloo 叫声(合成气泡音,品牌原创)。语义:

- 运动开始 = 两声上扬
- 休息开始 = 两声下沉
- 完成 = 欢快三连

当前预设为 E「灵巧啾噜」(默认)与 G「清透轻呼」,可静音。见 [0004](decisions/0004-voice-presets-chirrup-breeze.md)。语音播报为后期。

## 信息架构

底部可达:小窝(主页)、历史、设置。主页同时给出三种工作模式入口与快捷计时(1 / 3 / 5 / 10 分钟)。角色可点按互动,功能入口必须是明确的可点目标,不强迫与角色互动才能使用。

运行中进入全屏运行页:Zibloo 按上表状态出现,叠加该模式的计时信息。

意图上的入口形态是触手或气泡;具体视觉规格仍开放。

### 训练

运动时长 + 休息时长 × 组数,均可调。内置模板:经典 30/15×8、Tabata 20/10×8、力量 40/20×6、耐力 60/30×4。运行控制:暂停 / 继续、跳过当前段、结束。组数与下段预览。自定义命名预设(保存 / 复用 / 删除)属首版。

后期:多段自定义序列、预设文件分享、语音播报档。

### 专注

专注时长 15 / 20 / 25 / 50 分,短休息 3 / 5 / 10 分。长休息:每 N 个番茄(默认 4)进入,时长可调(默认 15 分)。运行页:圆环倒计时 + 第几个番茄 + Zibloo 专注状态。

后期:任务标签、今日番茄数 / 连续天数的完整统计展示。

### 提醒

一次性(X 分钟后或指定时刻)、每日固定、每周指定日、每 X 小时(可选日窗)。列表:名称、规则、启用开关;新建 / 编辑 / 删除。重启后规则必须仍生效。提醒方式:响铃 + 震动;单条配置与语音播报为后期。

### 历史与设置

历史记录每次训练 / 专注 / 提醒:类型、开始时间、时长、完成度。今日陪伴统计属首版。周图表、按类型筛选、标签为后期。

数据本地存储、无账号。整包备份导出 / 导入恢复(历史、提醒、自定义预设;版本化 JSON,导入须确认覆盖)属首版。

设置:中英双语、叫声预设 / 静音、备份。震动强度档与语音播报为后期。

## 可靠性(最高优先级)

1. 锁屏或切后台时,进行中的倒计时不暂停、不漂移;到点准时提醒。
2. 杀掉 App 后,已设置的提醒依然到点触发,不依赖 App 存活。
3. 重启后提醒规则不丢。

以上三条必须在安卓真机上人工验收,模拟器结果不算数。清单见 [`runbooks/device-acceptance.md`](runbooks/device-acceptance.md)。网页版不承诺后台可靠性。

计时逻辑、提醒调度、Zibloo 状态映射必须有单元测试。

## 开放问题

1. Slogan 中文定稿(草案「小计时 · 大日子」仅参考)
2. 比现有 E / G 更正式的叫声音频设计
3. 吉祥物正式素材规格与各尺寸导出(分层、腕足动作、解锁装饰)
4. App 图标
5. 网页版部署位置
6. 提醒文字自定义与长度限制
7. 触手 / 气泡入口的具体视觉形态
8. `SCHEDULE_EXACT_ALARM` 与 `USE_EXACT_ALARM`(上架审核更严;首版不上架,倾向前者 + 引导)
9. 闹钟响铃时长 / 循环策略
10. 网页版是否投入 Service Worker(倾向不做)
11. 轻养成解锁阈值
12. 国产 ROM 验收机型清单
