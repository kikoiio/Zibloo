# P0 原型

当前版本：[p0-v2](scratch/p0-v2/index.html)，本机预览：<http://127.0.0.1:4318/>。这是独立于生产代码的一次性 HTML/CSS/JS 原型，用于评审已选 2D 原图的动画与操作流程。

## 已落实的方向

用户已选择 [B2 主角色](scratch/character-study-v3/B2-fluid-extended.png) 与 [C3 品牌组合](scratch/character-study-v4/C3-zibloo-wordmark.png)，详见[选择记录](../docs/brand/selected-direction.md)。用户指出上版手工重画改变了形象和字标，该稿已撤回；当前直接呈现保存的原图，正式分层与动作素材仍需细化。

- 青绿/浅薄荷双配色，修长腕足与 S 形流线，继续禁止紫色。
- 恢复 B2 中央角色与 C3 上方原字标组合，保持原图字形、比例与轮廓。
- 渲染路线更新（2026-10-24）：用户改为在原本 2D 形象上做动画，覆盖此前的 3D 帧序列决定。当前只对 B2 原图做整体悬浮、旋转、轻微缩放与位移；模型、渲染参考及 Blender 工作流已移除。
- 点击主页空白水域游过去，连续点击可改向；点角色打招呼。方向键移动，Home 或「返回中间」复位；减少动态效果时直接切换位置。
- 专注与暂停安静陪伴；系统/应用减少动态效果会停止悬浮，页面隐藏会暂停动画。
- 桌面保留错落的三模式入口，窄屏将入口排在角色下方，保留明确可点目标。
- C3 原排版的角色与小写 zibloo 组合字标；页面无外部字体和脚本请求。
