# P0.2：B2 角色与 C3 品牌

一次性 HTML/CSS/JS 原型。按已选 B2/C3 方向手工绘制可变形矢量稿，用于评审角色在界面中的轮廓、动作和主要流程；不是最终品牌资产或生产实现。

## 打开

直接打开 `index.html`，或在本目录运行 `python3 -m http.server 4318 --bind 127.0.0.1`。本次工作已启动本机预览：<http://127.0.0.1:4318/>。

## 本版体验

- 青绿与浅薄荷角色、矢量小写 zibloo 组合字标；原始 B2/C3 参考在 `assets/reference-B2.png` 与 `assets/reference-C3.png`。
- 八条独立腕足用连续曲线变形，包含错开的舒展、卷曲与轻微悬游；眨眼、鼠标接近及点击/键盘打招呼。手工矢量稿的比例和轮廓仍需用户评审。
- 专注与暂停时角色安静；系统或应用的减少动态效果会停止变形；页面隐藏时取消动画帧，弹层出现时暂停其后的角色。
- 桌面保留错落入口，手机把三入口排在角色下方，避免功能目标压在腕足上。
- 训练、专注、快捷计时、暂停/继续、跳段、结束与完成反馈；提醒新建/编辑/启停/删除与反馈预览；历史、语言、声音试听及导出。
- 计时页保留青绿角色，以界面标识区分活动；不采用尚未确认的整只角色变色方案。
- 字标为 SVG 路径，页面可离线使用系统字体，无外部字体或脚本请求。

## 边界

数据仅保留在本次页面会话，刷新重置。首页陪伴时长只计入本次体验，历史周图及初始记录标注为示例。提醒不设置系统闹钟，声音为浏览器合成；后台/锁屏/重启可靠性仍需安卓实现后真机验收。

腕足形变由 JavaScript 更新 SVG 路径，按约 40ms 的更新门槛限频；这不是经过设备测量的帧率承诺。正式渲染路径与性能预算仍需按新角色评估。
