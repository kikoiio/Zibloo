# 当前原型声音预设

用户已选择第三轮 E「灵巧啾噜」和 G「清透轻呼」，用于继续原型。默认使用 E 是本次实现选择；已选 G 或静音的本机偏好继续保留，不将任意一种声音视为永久品牌定稿。

- `chirrup/`：E，打招呼、工作、休息、完成、日常提醒五段。
- `breeze/`：G，同样五种事件。
- `manifest.json`：默认、用户选定编号、来源文件、每段 SHA256。

文件逐字节复制自 `sound-lab/voice-round3/audio/` 用户试听过的版本，没有调音、变速、重新生成或更换声线。设置仅提供两种已选预设及静音，五种场景可单独试听；D/F 仅保留在历史试听页。

新访客及旧未选声音迁移到 E。旧 `temp-chirrup`、`temp-breeze` 分别迁移到 `chirrup`、`breeze`，显式静音不改变。一次性应用 URL 参数接受已选预设及上述旧别名，处理后清除，避免覆盖后续设置。

播放前等待用户手势启用的 AudioContext，开始时预取小音频。暂停、结束、切换设置、页面导航和关闭提醒/完成弹窗会取消尚未播放的叫声并停止当前叫声；同一时刻只播放一个角色叫声。训练关闭引导只关闭训练阶段声，完成声仍按全局提示音设置。快捷计时开始只启用音频，不播放开始叫声；专注/训练开始播放工作声。

原型提醒仍是交互预览，不注册真实系统闹钟。安卓后台、锁屏及重启可靠性尚未验收。
