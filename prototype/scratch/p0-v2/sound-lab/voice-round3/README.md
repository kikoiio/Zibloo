# 第三轮：临时无词声音

用户授权先用本地方式再尝试几个临时声音。无需账号、没有调用 Runway 或其他音频生成服务，没有消耗额度、下载模型、采集录音。前轮被用户否决，本轮未声称已获得听感认可。

试听：`http://127.0.0.1:4318/sound-lab/voice-round3/index.html`。D 轻声咕呼、E 灵巧啾噜、F 温暖哼鸣、G 清透轻呼，每组打招呼/工作/休息/完成/日常提醒五段，另有四种日常语气串联及四组招呼串联，共 25 个 44.1kHz、16-bit、mono WAV。

本轮继续使用程序合成，但替换音素拼接：多泛音声源、连续变化的元音共鸣、带限气息、细小的不规则漂移与力度变化、非等长的断续发声。庆祝尝试惊喜起音与短呼，休息尝试呼气收尾。不是有表演的真人录音或音频模型生成；这些变化能否被听成情绪，需要用户实际试听。

`python3 generate.py` 可复现，只依赖 numpy。`audio-checks.json` 记录时长和峰值/RMS。有效段 RMS 近似对齐，休息再降低约 1.2 dB；不声称各组感知响度完全相同。

## 暂用方式

在候选卡片点「在计时器中暂用」，进入原型设置并应用该临时声音。偏好保存在本机浏览器，第一/二轮收藏使用独立键不受影响。设置里可切换四组临时音、原临时提示音和静音；不点击应用则不替用户选择默认。

播放映射：工作→work、休息→rest、完成→complete、日常提醒→reminder、点击角色→greet。播放前仍在真实开始/继续点击中启用 AudioContext；提前获取并解码小型 WAV。每次播放重新检查设置与训练阶段引导，取消过期的异步播放；静音立即停止当前临时叫声。原角色与 logo 保持原图。

本机只作短小 DSP 运算和静态检查；浏览器验证继续使用已授权 GitHub Actions。技术检查不能替代听感、实体扬声器或安卓后台提醒验收。
