# 第二轮：Zi—bloo 的三种叫法

试听：`http://127.0.0.1:4318/sound-lab/voice-round2/index.html`。

本轮只探索名字辨识度与角色感，不替用户设定正式声音或替换计时器默认。第一轮原文件、原候选收藏保留。

| 方案 | 设计问题 | 制作方式 |
| --- | --- | --- |
| A 清楚叫名字 | 明确的 Zi—bloo 能否建立品牌记忆？机械发音感能否接受？ | 本机已有 eSpeak NG 英语音素合成，强制 `zi:blu:` 发音、调节速度与音高、柔化高频；不是录音或定制配音 |
| B 隐约像名字 | 能否在含糊、圆润的叫声里认出 Zi—bloo？ | 原创加法/共振峰合成，短 z/i、轻 b/l 过渡、较长 oo，保留语音线索 |
| C 只保留韵律 | 没有辅音，只留短—长轮廓时，是否仍像同一个伙伴？ | 原创无词泛音滑音，删除 z/b/l，保留呼唤时序与音调轮廓 |

每组 5 段：招牌叫声、开始工作、进入休息、全部完成、日常提醒。休息缩成柔软的 bloo；工作较短、上扬；完成更展开；日常提醒中间留白。

另有每组 4 种日常语气串联（工作→休息→完成→提醒）、A/B/C 招牌叫声连听，以及用同一句 B 叫声搭配用户已选 02–08 的七种质感。共 26 个 44.1 kHz / 16-bit / mono PCM WAV。02 是 B 的原声对照，其他六种保留本音并少量加入对应泛音/敲击/气息，不代表 A/C 已完成全部音色搭配。

原 B2 角色通过既有 SVG 原图封装显示。播放时只有整体轻抬，系统减少动态效果时停止；没有重画形象或宣称完成独立腕足动画。

## 复现与验证范围

`python3 generate.py`：需要 numpy 和系统 `libespeak-ng.so.1` 及其语音数据；不会下载模型或素材，不会播放到实体扬声器。eSpeak 采用同步音频回调，只把样本取回写入 WAV。API 依据 [eSpeak NG 官方头文件](https://github.com/espeak-ng/espeak-ng/blob/master/src/include/espeak-ng/speak_lib.h)，音素输入依据[官方音素说明](https://espeak.sourceforge.net/phonemes.html)。B/C 与音色叠加源均在脚本中，沿用上一轮的 `../generate.py` 作为质感源。

用有效段 RMS 近似对齐音量，并限制样本峰值不超过 0.69；不声称感知响度完全相同。`audio-checks.json` 记录长度、样本峰值与整体 RMS。生成只需短小的本机 CPU 运算；GUI、浏览器自动化和截图继续使用已获授权的 GitHub Actions。

技术检查验证可解码、非静音、峰值和安静收尾；网页验证比较播放、停止取消队列、音色试听、独立收藏与复制、原图引用、减少动态效果及四种宽度。不能由波形或浏览器断言名字被人听清、声音可爱/亲近或情绪合适，需用户实际试听后选择。当前机械合成发音只是可辨识度草稿，尚未进行配音与最终声音制作。
