# Zibloo 触手连接与变形研究 v4

本轮验证三个问题：根部过渡能否更平顺，侧面腕足是否有足够厚度，以及 Blender 与网页是否在同一网格上得到一致变形。延续 B2/C3 与 v3 的青碧／薄荷方向、四组动作，不覆盖历史资产或计时器页面。

## 做了什么

- 腕足截面的厚度系数由 0.78 调至 0.90，保留扁圆截面，改善侧面过薄。
- 对自动四边面控制笼的根部区域做局部正负交替平顺，缓解体素融合与自动重拓扑留下的细小起伏；远端和主要头部保持原有轮廓。
- 权重在低面网格的相邻顶点间局部平滑，让根部不同腕足与躯干之间的权重过渡更渐进；双色也只在连接区域做柔化。
- 远端直接在细分后的表面重新采样连续权重，避免截断插值权重产生微小折痕；低于颈部的腕足不再因截面半径判断而残留躯干影响，颈部使用平滑高度过渡。
- 先生成细分静止表面，再统一限制为四个归一化骨骼影响。Blender 与 GLB 都在这张网格上做线性蒙皮，避免“蒙皮后细分”和网页固定网格蒙皮的计算顺序差异。
- 工程保留隐藏的 `EDITABLE_Source_Forms`，新增 `EDITABLE_Weighted_Quad_Cage`；运行时网格单独保留，不冒充手工重拓扑。
- 评审页提供主视角、正面、侧面、背面，四组循环动作、暂停与模型下载。`comparison.jpg` 在同一机位、灯光下对比 v3/v4。

## 验证与产物

重型建模、CPU 渲染、依赖安装和浏览器检查均在已授权的 GitHub Actions 上顺序执行，本机只下载文件、读报告和提供 HTTP 预览。

除几何封闭性、逐顶点 1–4 个影响与权重归一化、动作循环、暂停切换、手机完整显示和减少动态效果外，本轮新增跨环境检查：记录 96 个网格采样点在 Blender 中的静止位置与四个动作中的变形位置，再恢复优化 GLB 量化坐标在逆绑定矩阵中的解码变换，匹配同一位置、比较姿态。这个检查只覆盖选定采样点和时刻，不代表完整拓扑、穿插或所有帧的美术验收。

2026-10-23（纽约时间）的[最终云端运行](https://github.com/kikoiio/Zibloo/actions/runs/40046469602)已通过，建模提交 `81303d5`。实际控制笼为 4,982 面、4,984 顶点，网页表面为 19,930 顶点；75 根骨骼，零非流形边，逐顶点权重归一化最大误差 `4.66e-8`。四个循环动作、暂停切换、四个视角、390 px 手机布局及减少动态效果均通过，未出现页面脚本异常。

GLB 从 2,529,884 字节压缩到 789,692 字节（约 771 KiB，减少 68.8%）。与 v3 的 739 KiB 相比增加约 4.4%，主要换取更厚的截面和统一变形表面。静止点匹配最大误差约 `0.000292`；四个动作所采样姿态的最大位置差约 `0.00185` 个模型单位，均值最大约 `0.000594`。这些是模型单位与选定点的观测，不能解释为所有顶点、所有帧完全相同。

已目视复核同机位 v3/v4 对比图、四个动作的分段帧、网页招手／庆祝／托珠、侧面与手机版。最终版本没有中间试验中出现的无权重静止触手和拉裂；前腕的托珠弯曲保持连续，触手侧面厚度增加，根部的小起伏有所减轻。推荐以 v4 继续评审；背面颈部一圈过渡仍偏硬，侧面局部轮廓及网页材质仍需人工处理，不能视为正式美术验收。

`output/` 为下载的完整交付，生成的大文件不提交公开仓库：

- `zibloo_flow_v4.blend`：Blender 4.5.3 LTS 工程。
- `zibloo_flow_v4.glb`：带 Meshopt 压缩、蒙皮与四组动作；网页需要 `MeshoptDecoder`。
- `zibloo_flow_v4_source.glb`：未压缩备份。
- `index.html`、`viewer.js`、字体：离线依赖齐全的 HTTP 评审页。
- 四个姿态 PNG/GIF，Focus 的正、侧、背面和透明图，`comparison.jpg` 与 `poses.jpg`。
- `report.json`、`optimization.json`、`browser-inspection.json`、`deformation-parity.json`：实际验证数据；`blender-landmarks.json` 为跨环境采样来源。

## 在 Blender 中继续编辑

打开工程后，在 Outliner 中显示 `EDITABLE_Source_Forms`。源形体与曲线路径用于定位造型；`EDITABLE_Weighted_Quad_Cage` 用于观察低面分叉、面环和原始权重。运行时网格已经固化了一级细分，改变隐藏控制笼不会自动更新运行时网格，继续编辑需从控制笼重建后再检查四影响限制及 GLB。

当前仍是可丢弃的造型、变形与导出原型。自动 QuadriFlow 没有建立经过艺术家整理的分叉面环，局部平顺也不能替代人工重拓扑；正式资产仍需整理根部面环、穿插、权重和动画控制器。
