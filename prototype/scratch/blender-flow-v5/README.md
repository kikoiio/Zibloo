# Zibloo 立体体积研究 v5

针对 v4 从侧面看仍偏扁的问题，修改实际前后体积与触手空间分布。保留四个动作和青碧／薄荷方向，作为独立原型评审。

## 改动

- 头部源网格的 Y 轴厚度增加 38%，略向后移，眼睛和高光同步贴到新的前表面。
- 八条触手在前后方向分别展开，前景腕足向前探、背景腕足向后伸；不再主要铺在 X/Z 平面。
- 触手截面厚度系数由 0.90 改为 1.02，保留柔软圆钝的末端。
- 托珠时两条前腕及光珠前移，维持接触关系。
- 静止与动作曲线分别沿整条触手平行传递截面框架，用两组框架的相对旋转驱动骨段；避免逐段最短旋转在 U 形折返处选取相反旋转轴而扭细。保留原有绑定方向与网页四影响线性蒙皮。
- 网页“侧面”按钮改为严格的 90° 方位。离线同样输出 90° 的待机与托珠侧面，并在相同相机、灯光和尺寸下重渲染 v4 作为对照。

## 验证

生成、CPU 渲染、依赖安装与浏览器验证全部运行在已获授权的 GitHub Actions。本机只处理脚本、读取产物和提供轻量 HTTP 预览。

沿用逐顶点权重完整性、四个动作循环、暂停切换、手机完整显示和 Blender／GLB 变形采样检查；另检查加深后的身体仍是一个封闭连通网格。`volume-comparison.json` 会记录同一区域的前后尺寸及新旧比例，避免以换相机冒充体积增加。

2026-10-23（纽约时间）的[最终云端运行](https://github.com/kikoiio/Zibloo/actions/runs/40048894899)已通过，建模提交 `a93e61d`。下载后目视复核了新旧同机位对比、Focus 主视角和 90° 侧面、四动作的分段帧、Focus 的全部 16 个预览帧，以及网页托珠／招手／庆祝、侧面和 390 px 手机截图。托珠前腕保持连续，未再出现中间版本的局部翻转与细带。

同一静止表面范围的测量如下，单位为模型单位：

| 测量 | v4 | v5 | 变化 |
| --- | ---: | ---: | ---: |
| 头部厚度 | 1.705 | 2.352 | +38.0% |
| 身体与触手的整体前后跨度 | 2.138 | 3.302 | +54.4% |
| 正面整体宽度 | 5.360 | 5.369 | +0.18% |

头部测量范围固定为 `1.05 < Z < 2.4`、`abs(X) < 1.1`；它表示同一上部区域的包围跨度，不能解释为所有截面均匀增厚了 38%。整体前后跨度包含触手的空间展开。

最终控制笼为 4,662 面、4,664 顶点，运行时表面 18,650 顶点，75 根骨骼，零非流形边，身体为单个封闭连通网格。每个运行时顶点有 1–4 个影响，权重归一化最大误差 `4.66e-8`。四个动作循环的最大采样接缝约 `0.000017` 个模型单位；暂停切换姿态无残留混合，手机四动作均完整入画，未出现页面脚本异常。

GLB 从 2,447,896 字节压缩为 773,856 字节（约 756 KiB，减少 68.4%）。96 个跨环境采样点的静止位置最大匹配误差约 `0.000296`，四个选定姿态的 Blender／网页最大位置差约 `0.00195` 个模型单位。这些检查覆盖指定采样点和时刻，不等于全部顶点与全部帧的美术验收。

[侧面对比](output/side-comparison.jpg)左侧为 v4、右侧为 v5；[完整对比](output/comparison.jpg)同时包含主视角。`animation-review.jpg` 和 `focus-frames-review.jpg` 是下载后的轻量接触表，`provenance.json` 记录云端来源、提交与三份模型文件的 SHA-256。

`output/` 包含工程、带四组动作的压缩 GLB、未压缩备份、四组 PNG/GIF、90° 侧面图、v4/v5 对比图和验证报告。主 GLB 使用 Meshopt，评审页已经配置解码器。打开 `index.html` 需要 HTTP 服务。

这仍是自动四边面和程序化绑定原型；厚度与空间分布改善不等同于人工重拓扑完成。低面控制笼、原始源形体与曲线路径保留在 `EDITABLE_Source_Forms`。

## 打开与继续编辑

本机评审页为 http://localhost:4320/ ，可切换“侧面”并拖动旋转。输出文件保持在本目录的 `output/`，大文件不提交公开仓库。

在 Blender 的 Outliner 中显示 `EDITABLE_Source_Forms`，可查看原始形体、曲线路径及 `EDITABLE_Weighted_Quad_Cage`。隐藏控制笼与运行时表面相互独立；修改控制笼后，需要重建运行时网格、权重与导出文件，再复核动作。

这轮适合继续评审体积和空间层次。颈部及分叉的局部过渡、急弯的线性蒙皮收缩和网页材质仍需正式制作时人工处理；当前不是完成美术验收的资产。
