# Zibloo 品牌角色探索 v2

2026-10-22。使用内置 image_gen 生成三张静态概念板；未使用 CLI/API fallback。

## 设计依据

用户否决了旧角色的玩偶感，以及 v1 的生物写实与令人不安的细节。当前探索：简洁有机轮廓、克制的表情、修长而柔软的腕足；悬浮状态与主动互动；禁止紫色。品牌可能延伸到计时之外，不将秒表或时钟固化进标志。

每板从左到右为单色标志与缩小预览、彩色待机角色、互动姿态。A 有机几何；B 流线符号；C 柔和体积。

## 观察与边界

A 的轮廓简洁；B 的 S 形流线和主动捧泡姿态值得继续；C 亲切，但头部比例和眼睛仍偏传统吉祥物。三组均为生成式位图草案，不是正式矢量标志。标志与大角色的轮廓一致性、腕足结构和数量尚需人工重绘约束。板上的缩小图不代表真实 24/32 像素测试。姿态变化不证明自然连续动画或可用绑定。尚未替换现有应用素材；未确定最终品牌方向。
