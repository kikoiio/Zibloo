# Zibloo 灵动与变色研究 v6

用户反馈 v5 仍笨重、缺少章鱼的灵活感，并要求核实章鱼变色能力、尝试变色。本轮把评审问题限定为：在保持真实侧面体积的同时，触手能否更修长、运动更有先后；变色是否有局部展开的感觉。

## 造型与运动

- 头部正面宽度减少约 8%，Y 方向仍在 v2 基础上加深 32%，保留饱满侧面。
- 主腕足向外延展约 12%；后景腕足适当收拢，减少轮辐感。根部保持厚度，中后段收细约 25–45%，末端保持圆钝。
- 每条腕足由 9 段增为 12 段，总共 99 根骨骼。弯曲沿长度方向传递，各腕足使用不同相位与幅度，加入末端跟随和轻微身体倾摆。
- Focus 的两条托珠前腕约束末端扰动，维持光珠接触。其他动作的身体抬升与腕足动作错开，减少整只同步弹跳的感觉。
- 保留连续传输的截面方向、共同细分静止表面、四影响线性蒙皮及逐点权重检查。

## 变色依据与呈现

[章鱼颜色资料核实](../../../docs/brand/3d/octopus-color-research.md)列出已读论文和物种边界。部分章鱼有浅色到深棕、棕白斑纹及局部蓝绿反光；各物种不同，不能据此声称章鱼具有任意 RGB 色域。青碧仍是品牌配色，沙色、赤褐与墨棕是参考章鱼体色后选取的卡通色，不作为某物种的科学色卡，也不对应固定动物情绪。

| 预设 | 外背 | 腹侧 |
| --- | --- | --- |
| 青碧（默认） | `#236E69` | `#A3D9C9` |
| 沙色 | `#B69A68` | `#F1E4C9` |
| 赤褐 | `#A45338` | `#E6B58A` |
| 墨棕 | `#433D35` | `#B8ADA0` |

评审页提供四个颜色按钮和一次性演示。手动切色时，颜色带从头部向触手渐进，叠加低频、低对比的大块色差；眼睛与光珠保持原色。选择新颜色会接续当前画面，演示可停止、结束后返回开始前的配色。动作暂停时仍可手动变色；开启系统减少动态效果时直接切换颜色并禁用演示。这是刻意放慢的视觉演示，不模拟真实色素囊的速度或细胞结构。

网页读取并还原 GLB 的归一化颜色后，保留浮点颜色缓冲。过渡结束后不再更新颜色；图案固定在静止网格上，随蒙皮移动。

## 文件与编辑

- `output/zibloo_flow_v6.blend`：可编辑源形体、低面控制笼、99 骨动作，以及身体自定义属性 `skin_stage`。在 `Zibloo_Quad_Skin` 的 Custom Properties 将它调到 0/1/2/3，分别查看青碧／沙色／赤褐／墨棕；小数值可查看空间渐变。
- `output/zibloo_flow_v6.glb`：基础青碧配色、四组动作和 Meshopt 压缩。动态变色由 `viewer.js` 驱动，并未烘焙进通用 GLB 的材质动画。
- `output/zibloo_flow_v6_source.glb`：未压缩备份。
- 四动作 PNG/GIF、Focus 的正／侧／背面，四色 PNG 与 `colors.jpg`、过渡中间图、新旧同机位 `comparison.jpg`。
- `report.json`、`volume-comparison.json`、`optimization.json`、`deformation-parity.json`、`browser-inspection.json`：实际检查报告。

重型建模、CPU 渲染、依赖安装与浏览器检查均由已获授权的 GitHub Actions 执行。本机只编辑小文件、下载产物、读取图片和提供轻量 HTTP 预览。工作流支持复用已渲染的产物，仅在云端重打包与检查网页，避免为页面检查重复渲染。

## 验证状态

2026-10-23（纽约时间）的[最终云端检查](https://github.com/kikoiio/Zibloo/actions/runs/40051440950)已通过，使用建模提交 `c4e4806` 的渲染产物和检查提交 `aa98ec9` 的评审页。模型与渲染来自运行 `40050709788`，网页复核复用这些产物。`provenance.json` 分别记录两个阶段的来源和三份模型文件的 SHA-256。

最终控制笼为 3,791 面、3,793 顶点，运行时 15,166 顶点、99 根骨骼；身体是单个封闭连通网格、零非流形边。每个运行时顶点有 1–4 个影响，权重归一化最大误差约 `4.56e-8`。头部同一区域的厚宽比为 1.20，厚度保留 v5 的约 95.6%，收细腕足后侧面仍有体积。

四动作循环的最大采样接缝约 `0.000017` 个模型单位，暂停切换姿态没有残留混合。96 个点在四个选定时刻的 Blender／网页最大位置差约 `0.00162` 个模型单位。GLB 从 2,607,424 字节压缩为 997,936 字节（约 975 KiB）。相对 v5 文件变大，主要因为增加了骨段及各段独立变化的动画。

网页验证包括四色实际顶点颜色变化、两眼材质不变、暂停动作时变色、演示完整结束和返回、停止演示、手动选色取消演示，以及系统减少动态效果下的直接切色。通过控制浏览器时钟，在真实过渡约 49.6% 时定格，采样点的插值进度跨度约 0.99；截图可见头部先转赤褐、较低腕足保留青碧，证明是空间展开的色带。390 px 手机四动作均完整入画，无水平溢出和页面脚本异常。

下载后已目视复核新旧主视角／同机位侧面、四动作各 16 个预览帧、四色 Blender 渲染与过渡中间图、网页四色／渐变／侧面及手机截图。未见前腕翻转成细带或触手拉裂。检查只覆盖所记录的采样点、姿态和图片，不能替代全部动作帧和穿插的正式美术验收。

本机预览：http://localhost:4321/ 。旧版 http://localhost:4320/ 保留对照。

这仍是可丢弃的造型、运动与变色原型。自动 QuadriFlow 和程序化绑定不能替代人工分叉面环、权重及动作控制器；视觉过渡也没有模拟真实皮肤的光学与神经控制。
