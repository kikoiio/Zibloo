# Zibloo v7：更大的动作与眼神

独立、可丢弃的动作评审原型，保留 v6 的立体体积、青碧/薄荷双色和变色实验。它用来判断动作与情绪是否足够清晰，不是正式制作资产。

## 本轮变化

| 动作 | 身体与腕足 | 眼睛 |
| --- | --- | --- |
| Idle | 更明显的悬浮、前后错开的行进弯曲、末端回卷 | 视线游移、两次自然眨眼 |
| Greeting | 主腕足高举成 S 形，末端横向挥动，其余腕足延迟跟随 | 抬眼、左右开合差异、单眼眨眼 |
| Focus | 前探、前腕环抱光珠，后腕保持缓慢游动 | 缩短眼形，视线朝右下方光珠集中 |
| Celebrate | 先收拢蓄势，随后上跃并展开两条主腕足，再恢复 | 两只闭合弯眼，随动作逐步展开与恢复 |

眼神通过 4 个新增骨骼控制，眼球、高光和闭合笑眼均跟随 Head，动画直接烘焙进同一套四个 GLB 动作。没有嘴、眉毛、吸盘或写实皮肤。皮肤变色仍由评审页实时改变顶点色；Blender 工程另有 `skin_stage` 0–3 控制，基础 GLB 保存青碧配色。

## 查看

预览页支持四动作、四配色、渐变演示、正侧背面、“眼神特写”和动作进度条。进度条会暂停在所选姿势；切换中暂停会取消混合，显示所选动作的实际姿势。

- `output/expressions.jpg`：相同机位的四种眼神。
- `output/motion-keys.jpg`：每个动作的五个关键时刻。
- `output/<action>.gif`：压缩动作示意；真实连续动作请看预览页。
- `output/zibloo_flow_v7.blend`、`output/zibloo_flow_v7.glb`：工程与网页模型。

## 生成与验证

使用已授权的公开仓库 GitHub Actions Ubuntu runner：`.github/workflows/blender-expression-v7.yml`。Blender 4.5.3 LTS、CPU 两线程；本机不运行 Blender、依赖安装或浏览器自动化。

模型与动画生成后，检查连续封闭外皮、权重归一、动作循环、Blender/GLB 变形一致性、相对头部的眨眼/眯眼/笑眼控制、暂停切换、颜色渐变及手机取景。视觉观察与实际结果如下。

保留自动 QuadriFlow 控制笼及源曲线。人工整理根部面环、完善局部权重和生产级动画控制器仍是后续工作。

## 已完成的评审

- [模型与渲染](https://github.com/kikoiio/Zibloo/actions/runs/40053382966)，模型脚本提交 `287b13304fdbf8c771d156fbb084245e21927e20`。
- [最终网页检查](https://github.com/kikoiio/Zibloo/actions/runs/40054301740)，复用模型产物，页面提交 `4385aa3`。
- Blender 4.5.3 LTS；3,791 面自动控制笼、15,166 个运行时身体顶点、103 根骨骼。优化 GLB 917,428 字节，约 896 KiB。
- 四组动作循环、眼睛相对头部的开合/眨眼/笑眼控制、切换中拖动进度条检查通过；暂停姿势误差为 0。
- 最大单帧腕足转角：Idle 3.45°、Greeting 10.93°、Focus 2.67°、Celebrate 15.51°。大幅动作通过逐段旋转切线后积分产生，避免直接挪动路径点时的急转。
- Blender 与优化 GLB 的 96 个身体参照点最大误差约 0.00235 模型单位；循环首尾最大误差约 0.000022。权重归一误差小于 4.6e-8。
- 手机每组动作检查 24 个时刻，最大水平/垂直投影范围约 0.798 / 0.506，均在画面内。四配色、局部渐变、演示返回/停止及减少动态效果检查通过。

已目视复核四组动作的全部 16 张渲染帧、四种眼神、正侧背面、网页配色渐变与手机画面。招呼时主腕足完整抬起并回摆；庆祝时先下沉收拢，再抬升展开，配合弯眼；Focus 维持较安静的托珠状态。建议先用 Greeting / Celebrate 评审动作幅度，再用“眼神特写”查看开合与视线。

`output/motion-comparison.gif` 将已有云端 v6/v7 帧同步拼在一起，便于比较招呼与庆祝；这是本机的轻量图片合成。完整连续动作以网页 GLB 为准。模型及工程校验值见 `output/provenance.json`。

这轮通过的是技术检查和视觉复核，情绪强度仍待用户评审。背面颈部仍有轻微凹纹，根部面环及极端姿势的局部权重需要正式制作时人工处理。

后续用户反馈：八腕近端、尤其与躯干连接处仍显僵硬。v7 的技术通过没有解决这个动作体验问题；继续用 [v8](../blender-flow-v8/README.md) 评审近端活动和全身协调。
